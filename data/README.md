# data/

Local working directory. **Contents are git-ignored on purpose.**

| Folder | Contents |
|---|---|
| `snapshots/` | Frames saved with the `s` key in the camera preview. Used to record baseline image quality before and after the NoIR modification (Stage 13). |
| *(later)* `mrl/` | MRL Eye Dataset, downloaded locally for Stage 6. Never committed — it is large and externally distributed. |
| *(later)* `test_sessions/` | Self-collected test recordings (Stage 15). Never committed — they contain subjects' faces and need consent to share. |

Only this README and `.gitkeep` files are tracked, so the folder structure survives
a fresh clone while the contents stay local.
